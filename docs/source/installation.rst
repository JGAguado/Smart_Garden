🛠️ Installation
===============

Deployment
-----------

.. Caution::
    The installation of the Smart Garden should be done in a dry area, preferably indoors and far away from any source of water that could be spilled over the board.

After the board has been programmed physically, at least once, it should be ready to receive further updates :term:`OTA`. This means that 
the |Product| can be deployed and installed on it's final place, like an electric cabinet where the solenoid valves cables arrive from the garden:

1. Locate an empty space on the DIN rail where you can install the enclosed |Product| and mount it.
2. Unscrew the terminal blocks, insert the wires comming from the actuators (solenoid valves or water pumps) and screw them back. 

.. Important::
    If you are using an actuator with polarity, like a DC solenoid valve or a water pump, pay attention to the polarity printed on the PCB's silkscreen.    

3. Check that the switches have been set to the right mode 24VAC or 12VDC for each relay.

4. If you intend to use the auxiliary input/output port for reading any sensor/pushbutton, make sure it's correctly connected.

4. Power the |Product| through the Jack port.
