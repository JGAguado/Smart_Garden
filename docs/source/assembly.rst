🏗️ Assembly
============================

Soldering 
----------
.. Important::
    Please note that some components in this board need to be soldered.

The |Product| comes as a set consisting on a :term:`SMD` pre-soldered board to which you will need to mount the following components:

* 4x SRD-12VDC-SL-C relays.
* 4x 2-Pin 2mm-pitch screw terminal block.
* 1x Power Jack connector
* Optional 2.54mm-pitch male pins, in case you want to expand the connectivity and/or read external sensors.


The soldering of these two components is quite fast, just make sure not to bend any of the relays pins. If you have never soldered or you want to improve your soldering techniques I recommend you 
the `Adafruit Guide To Excellent Soldering <https://learn.adafruit.com/adafruit-guide-excellent-soldering>`_


Last but not least, it is highly recommended to mount the |Product| on an enclosure, like the one suggested.
